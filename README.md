# Evolai

Sitio de Evolai (canal **Gabito Tu IA**), publicado con GitHub Pages:
https://gabrielbarrientos99.github.io/evolai/

| Archivo | Para qué |
|---|---|
| `index.html` | Página principal: canal, último experimento y la app **Automatizacion Videos** |
| `privacidad.html` | Política de privacidad (la pide Google para pasar la app OAuth a Producción) |
| `estilos.css` | Estilos compartidos |

Las URLs de `index.html` y `privacidad.html` están registradas en Google Cloud → Google Auth Platform → Información de la marca. No las cambies de nombre sin actualizarlas allí.

Para publicar cambios: edita, luego `git add -A && git commit -m "..." && git push`. GitHub Pages se actualiza en 1–2 minutos.
