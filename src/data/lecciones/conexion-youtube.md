# 00 · General YouTube

Todo lo que comparten los canales.

| Carpeta / archivo | Qué es |
|---|---|
| `tutorial/index.html` | Guía: configuración de Google Cloud, kit de video con Claude, referencia de la API y laboratorio |
| `credenciales/client_secret.json` | Identidad de la app OAuth "Automatizacion Videos". Una sola para todos los canales. **No compartir.** |
| `plantilla_cuenta/` | `cuenta.json` + notebook base para crear `cuenta_<alias>/` |
| `musica/` | Música de fondo: originales libres de reclamos, pistas de CapCut (solo para CapCut) y generadores |
| `curso/` | Lecciones del curso (.md), sus imágenes (`img/`) y los PDFs con plantilla profesional (`pdf/`, se generan con `herramientas/exportar_pdf.py`) |
| `skills_exportadas/` | Las skills de edición de video en .zip para instalarlas en otra cuenta de Claude |
| `requirements.txt` | `pip install -r requirements.txt` |

Proyecto de Google Cloud: `automatizacion-videos-514616`.
